Desktop vault

One encrypted file for the logins on your machines.

Safora keeps servers, mailboxes, websites, file transfer, and databases in a vault on your computer. The master password seals that file before anything is written. A synced folder only ever receives the sealed copy.

What it stores

Each collection has the fields that belong to it.

Search covers the name, the notes, and every field. Add, edit, and delete stay inside the unlocked vault.

  1. Server

    SSH hosts, admin users, and private keys.

    Host · port · username · password · system · private key

  2. Email

    Mailbox logins and the IMAP and SMTP servers behind them.

    Address · username · password · IMAP · SMTP

  3. Website

    Site logins and the address they belong to.

    URL · username · password

  4. FTP / SFTP

    File transfer hosts, the protocol, and the remote path.

    SFTP, FTP, or FTPS · host · port · path

  5. Database

    Engines, hosts, database names, and accounts.

    PostgreSQL, MySQL, MariaDB, SQL Server, MongoDB, Redis, SQLite

How it is sealed

The password stays in the app. The disk gets ciphertext.

Safora derives a key with PBKDF2-SHA-256, 600,000 iterations, and encrypts the vault with AES-256-GCM. Rust writes that envelope to the application-data directory, replacing the file atomically and tightening Unix permissions.

  1. Local first

    The vault file is created on this computer. Unlocking it needs the master password you chose. The app cannot recover that password.

  2. Idle lock

    Leave Safora unused and it locks itself, then asks for the master password again. You pick the idle time, or turn the lock off.

  3. A sealed cloud copy

    Sync does not sign in to Google or Microsoft. It writes Safora/vault.enc into the Google Drive or OneDrive folder already connected on this computer.

  4. Still an early build

    Safora has not had a security audit. Do not keep production secrets in it until the implementation has been reviewed and tested. Protect the operating-system account, and keep your own backup of the encrypted file.
